## PROJECT OVERVIEW

**Project name:** Smart Waste — Intelligent Household Waste Classification System
**Purpose:** Help citizens correctly dispose of waste by scanning a QR code next to a trash bin, taking a photo of their item, and receiving an AI-powered classification result. The system also monitors bin fullness and notifies responsible personnel via Telegram.

## DATABASE SCHEMA (Prisma models)

```prisma
model User {
  id           String   @id @default(uuid())
  telegramId   String?  @unique
  phoneNumber  String?
  ecoPoints    Int      @default(0)
  createdAt    DateTime @default(now())
  classifications Classification[]
}

model Area {
  id                String  @id @default(uuid())
  name              String
  responsiblePerson ResponsiblePerson?
  bins              Bin[]
}

model ResponsiblePerson {
  id         String  @id @default(uuid())
  name       String
  telegramId String
  area       Area    @relation(fields: [areaId], references: [id])
  areaId     String  @unique
}

model BinCategory {
  id    String @id @default(uuid())
  name  String         // e.g. "Recyclable", "General Trash"
  color String         // hex color for UI
  icon  String         // emoji or icon name
  bins  Bin[]
}

model Bin {
  id          String      @id @default(uuid())
  qrCode      String      @unique
  location    String
  isFull      Boolean     @default(false)
  area        Area        @relation(fields: [areaId], references: [id])
  areaId      String
  category    BinCategory @relation(fields: [categoryId], references: [id])
  categoryId  String
  classifications Classification[]
  notifications   Notification[]
  createdAt   DateTime    @default(now())
}

model Classification {
  id          String   @id @default(uuid())
  imageUrl    String
  result      String   // category name returned by AI
  confidence  Float
  pointsEarned Int     @default(10)
  bin         Bin      @relation(fields: [binId], references: [id])
  binId       String
  user        User?    @relation(fields: [userId], references: [id])
  userId      String?
  createdAt   DateTime @default(now())
}

model Notification {
  id        String   @id @default(uuid())
  type      String   // "BIN_FULL" | "BIN_EMPTIED"
  message   String
  sentAt    DateTime @default(now())
  status    String   @default("SENT")
  bin       Bin      @relation(fields: [binId], references: [id])
  binId     String
}

model Admin {
  id       String @id @default(uuid())
  email    String @unique
  password String
}
```

## CORE FEATURES TO BUILD

### 1. PWA — User Flow (mobile-first)
- QR code is scanned → opens `https://yourapp.com/scan?binId=XXXX`
- Page requests camera access
- User snaps a photo of their trash item
- Photo is uploaded to Cloudinary, URL is sent to NestJS
- NestJS calls OpenAI Vision API with the image URL
- AI returns: category name, confidence %, short description
- User sees result: which bin to use, eco points earned
- Points saved to user profile (identified by Telegram ID or anonymous session)

### 2. Admin Dashboard (desktop-first, route: /admin)
- Login with JWT
- Manage BinCategories (add / edit / delete — default: Recyclable, General Trash)
- Manage Areas and ResponsiblePersons
- Manage Bins (add bin, generate QR code, assign to area + category)
- View all Classifications (image, result, confidence, timestamp)
- View all Notifications history
- Manually mark a bin as full or empty
- Leaderboard: top eco-point users

### 3. Bin Fullness Notification Flow
- Raspberry Pi (or simulated endpoint) sends POST /bins/:id/fullness { isFull: true }
- NestJS updates bin status
- NestJS finds responsible person for that bin's area
- Sends Telegram message via Bot API: "Bin [location] is full. Please collect."
- Notification is logged in DB

### 4. Telegram Bot
- One-way notification bot (no replies needed for v1)
- ResponsiblePerson must have a Telegram ID registered in admin
- Bot sends formatted message with bin location and area

### 5. Eco Points System
- Each successful classification = +10 points
- Points stored per user (Telegram ID or anonymous)
- Leaderboard visible on both PWA and Admin

const response = await openai.chat.completions.create({
  model: "gpt-4o",
  messages: [
    {
      role: "user",

          type: "image_url",

    }
  ]

## CODING STANDARDS

- NestJS: use Modules, Services, Controllers, DTOs, Guards strictly
- Prisma: never write raw SQL unless necessary
- React: functional components only, custom hooks for logic
- All API responses follow: `{ data, message, success }`
- Environment variables in `.env` — never hardcode secrets
- Validate all inputs with class-validator in NestJS DTOs
- Use async/await — no .then() chains
